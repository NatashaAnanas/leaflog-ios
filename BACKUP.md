# Резервное копирование

Профиль → **Резервная копия**. Ничего не отправляется автоматически: вы сами выбираете место в системном «Файлы» (iCloud Drive, «На iPhone», внешний диск).

## Формат `.leaflogbackup`
```
"LEAFLOGBK1\n" | UInt64 BE длина манифеста | манифест JSON | блобы фото (по порядку manifest.photos) | SHA-256 всего предыдущего (32 байта)
```
Манифест: `formatVersion` (сейчас 1), версия приложения, дата экспорта, настройки, виды ухода, растения (с правилами, событиями, заметками), метаданные фото (id, даты, подпись, размер, SHA-256).
В копию входят все записи, фото и настройки; миниатюры пересоздаются при импорте.

## Импорт
1. Файл копируется во временное место и **проверяется**: заголовок, версия (более новая отвергается), контрольная сумма файла, манифест, ссылочная целостность (виды ухода, обложки, фото↔растения, уникальность id), размер/хэш/читаемость каждого фото. Данные приложения при этом не меняются.
2. Показывается сводка (дата, число растений, записей, заметок, фото) и подтверждение «Заменить текущие данные?».
3. Применение: новые файлы фото записываются без удаления существующих; удаление старых записей и вставка новых — **одно сохранение** (при ошибке откат, новые файлы удаляются); после успеха удаляются файлы, которых нет в копии; настройки применяются; напоминания пересчитываются.
Ошибка на любом шаге не повреждает текущую коллекцию (проверено тестами: повреждённый, обрезанный и чужой файл, будущая версия).

## Удаление приложения
Удаление Leaflog с телефона может удалить все локальные данные (база и фото лежат в песочнице приложения). Перед удалением, переустановкой или сменой подписи сделайте копию и сохраните её в «Файлы». Восстановление: установите приложение → Профиль → Резервная копия → Импортировать.
При бесплатной подписи (Personal Team) сборка живёт около 7 дней; обновляйте её установкой из Xcode **поверх** прежней с тем же Bundle Identifier — данные сохраняются.
