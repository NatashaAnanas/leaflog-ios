## Выполнено
- Проект Xcode (iOS 17+, SwiftUI + SwiftData), публичный репозиторий `NatashaAnanas/leaflog-ios`, `.gitignore` до первого push.
- Растения: добавление (достаточно названия, вид отдельно, фото из медиатеки/камеры), правка, обложка, архив/восстановление, удаление с подтверждением, поиск, активные/архивные.
- Карточка: быстрые действия, задачи и просрочка, последняя дата по каждому виду, расписания, календарь и история, фотодневник, заметки, советы.
- Виды ухода: 5 встроенных + свои (название, цвет, иконка), отключение без потери истории.
- Расписание: дни/недели/месяцы, расчёт от фактической даты, пересчёт при смене интервала и правке истории, snooze отдельно от выполнения.
- Календари: общий (с фильтрами растений и видов) и растения; выполнено/запланировано/просрочено различаются формой маркера; внесение ухода за выбранную дату; правка и удаление.
- Фото: неизменяемая дата добавления + редактируемая дата снимка (из EXIF, иначе текущая), подпись, лента/сетка, обложка, удаление, миниатюры, обработка вне главного потока.
- Заметки: CRUD, `createdAt/updatedAt`, скрытие даты.
- Локальные уведомления: план из правил и истории, группировка по дням, повтор просрочки, действия «Выполнено»/«Отложить», маршрутизация по нажатию, сверка при запуске и возврате.
- Советы: 10 профилей + общий, сезоны и полушарие, собственные рекомендации растения.
- Резервная копия: экспорт/импорт через «Файлы» с проверкой целостности и подтверждением.
- Light/Dark, Dynamic Type (включая accessibility-размеры), подписи VoiceOver, локализация (русский, `Localizable.xcstrings`).
- Тесты: unit + UI (см. QA.md). Документация. Установка на iPhone.

## Блокеры и замечания
1. **Нативная панель симулятора в приложении Claude** недоступна: инструмент требует `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer` (нужен ваш пароль). Работа шла через `DEVELOPER_DIR` без изменения системных настроек; симулятор проверялся через `xcodebuild`/`simctl`/XCUITest. Команду можете выполнить сами:
   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```
2. **Подпись:** Personal Team (бесплатный Apple ID) — профиль действует около 7 дней. Профиль для `com.natashaananas.leaflog` создан Xcode автоматически через `-allowProvisioningUpdates` (регистрация App ID в вашем бесплатном аккаунте). Один из двух найденных сертификатов Apple Development отозван; используется действующий (до 05.09.2027).
3. На iPhone **не** меняли дату и не удаляли приложения или данные.
